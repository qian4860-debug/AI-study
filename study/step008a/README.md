## 模型有效性合同

`resident_model.py`是可复用的主机侧协议模型，不是已部署的AXI/PCIe驱动。它产生真实加载命令，测试台逐个检查host_ready握手；若硬件不接受计划中的写入，回归立即失败。

- 模型身份包含权重、偏置、形状、量化配置和布局版本，不能仅按网络名称缓存。
- begin_model开始不同模型上传时立即使旧模型失效，避免部分覆盖后仍运行旧模型。
- 每次实际接受写入后调用acknowledge_write；ready拒绝不得前移计数，写入必须按序。
- 只有全部参数写入确认后，finish_model才使模型有效；未完成不能生成运行输入。
- 同模型只生成16项输入写入；换模型重新加载154项参数。
- 主机策略对reset/掉电/上传中断保守失效；RTL的RAM仍保留，但软件重新确认完整模型后才运行。

本次专门覆盖A→B、B热输入、B→A、reset后A全重载、reset后A热输入，以及B上传7项后中断、重置并全重传。中断场景真实接受177次主机写入（7项旧上传前缀+154项全重传+16输入）。独立5种运行中复位重启仍验证硬件保留RAM，不混同主机缓存有效位策略。
